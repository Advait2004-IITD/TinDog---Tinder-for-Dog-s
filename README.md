# TinDog - Tinder for Dogs 🐕

A fun and modern landing page for a dog dating app called **TinDog**. This project showcases a responsive, visually appealing website built with HTML, CSS, and Bootstrap 5.

## Features

✨ **Easy to Use** - Intuitive interface designed for dog owners of all tech levels

👑 **Elite Clientele** - Access to premium dog profiles from around the world

❤️ **Guaranteed to Work** - Find the perfect match for your furry friend or get your money back

## Pricing Plans

- **Chihuahua Plan** - $0/month (Free)
  - 5 Matches Per Day
  - 10 Messages Per Day
  - Unlimited App Usage

- **Labrador Plan** - $15/month
  - Unlimited Matches
  - Unlimited Messages
  - Unlimited App Usage

- **Mastiff Plan** - $29/month (Premium)
  - Priority Listing
  - Unlimited Matches & Messages
  - Unlimited App Usage
